# Aromía · Placer en miniatura

Web de Aromía publicada en Cloudflare: https://aromia.webs-pe.workers.dev/

Cada cambio que se sube a la rama `main` se publica solo en Cloudflare.

- **datos.js**: contacto, categorías, productos, presentaciones y precios.
- **img/**: fotos. Cada foto tiene dos tamaños (`nombre.jpg` 1280 px y `nombre-sm.jpg` 640 px). Para cambiar una, reemplaza ambos archivos con el mismo nombre.
- **fonts/**: tipografías oficiales (ver `fonts/LEEME.txt`).
